## 本轮：nextmoe 布局复核、四语与页面导航

- 已逐项对照 nextmoe 认证、个人资料、开发者与管理台源文件。认证移除登录/注册 Tabs，恢复底部切换入口；个人摘要改为居中头像与身份信息、约 19rem 左列；开发者首页使用全宽介绍与分区内容，说明页和控制台分开；管理台使用全高左侧栏。对齐范围与保留差异见 [布局复核](../ui-layout-audit.md)，不宣称像素级一致。
- 新增 LanguagePicker、NavigationProgress、ProfileSummary、LandingLayout 至共享 UI，现有 PageFrame/Sidebar 增加完整侧栏能力，公开组件共 61 个。Navbar 在 1024px 以下使用抽屉，修复 820px 英文管理台的横向溢出。
- 页面使用约 160ms 轻量淡入/位移、布局使用约 140ms 淡入淡出，out-in 顺序避免两套身份表单同时可操作。进度条由 Nuxt 页面加载钩子驱动，短导航不闪烁、结束/错误会清理，不宣称真实完成百分比；减少动态效果时取消位移。
- 前端支持 zh-CN、zh-TW、en、ja。每语言一个 src/lang 文件，内部按领域分组，公共入口仅注册/映射；类型约束完整键结构。选择器显示原生语言名及选中项，支持键盘、Cookie 持久化、SSR 无效语言回退，切换不导航或清空表单。
- 邮件 API 仍只发送其支持的 zh-CN/en：繁中映射 zh-CN、日文映射 en。没有修改 Go DTO、身份 Origin、CSRF、Cookie 或 OAuth 上游。offline_access 已添加四语的离线授权说明，不暗示授权管理页面已开放。
