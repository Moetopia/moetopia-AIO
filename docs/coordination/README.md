| 所有者 | 写入范围 | 进度入口 |

两侧开始工作先读本索引和另一侧状态；各自只更新自己的状态文件。状态至少写明日期、正在做的内容、已经完成且验证的接口、兼容影响、需要另一侧接入的事项和验证限制。状态和接口以共享文件事实为准，不假装自动通知已送达。

业务接口由 Go/Huma 生成 OpenAPI 与 TypeScript，生成包由后端生成器维护，前端只读生成产物、维护自身调用适配。稳定接口的破坏性变更先记录影响，不能靠改 mock 掩盖不兼容。OAuth/OIDC 是标准协议，交互业务接口单独记录。

AGENTS、README、根 package.json、锁文件、共享脚本和总进度属于公共文件：先检查另一侧正在做什么，尽量只改自己拥有的文件；需要对方修改时写入待办，不同时重写公共文件。本规则不要求每次普通代码变更都请求用户批准。

测试数据库使用各运行器新建的专属资源。不得停止另一对话的开发进程、占用其固定测试端口或执行清空/重置共享开发库。暂时不存在 Git，仍不得自行初始化、提交或使用 reset/clean/stash。
