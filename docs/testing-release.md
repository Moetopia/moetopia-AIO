## 身份与授权场景

1. 注册验证、密码登录、恢复密码、改邮箱、近期认证与会话旋转。
2. GitHub/Google 首次登录、供应商拒绝、过期 state、绑定冲突及最后登录方式解绑。
3. Authorization Code + PKCE 正常登录、错误 verifier、PKCE 降级、回调地址篡改、授权码过期和重放。
4. OIDC issuer/audience/nonce/签名错误、UserInfo subject 不匹配，以及拒绝把 ID Token 用于 API。
5. 并发消费授权码、并发刷新、旧刷新令牌重用、事务失败和令牌族撤销。
6. Client Credentials 只具备应用权限，无法获得用户身份或越权查询用户。
7. 用户拒绝授权、撤销应用、暂停应用、账号冻结、会话撤销与真实传播窗口。
8. 两个独立 origin 的 SSO、退出后重新登录、跨账号切换及不同 SameSite 条件。
9. 密钥轮换后新旧令牌验证、服务重启、旧公钥退出和密钥泄露应急。
10. CSRF、开放重定向、伪造代理头、账号枚举、暴力尝试和敏感日志泄露。

标准行为以 [身份与安全](identity-security.md) 为依据。并发刷新测试需有明确客户端策略，不能把合法重试全部误判为攻击后声称体验正确。

注册策略另验默认邀请、后台授权切换与审计、开放/邀请切换后的新账号准入、已有账号不受影响，以及第三方首次登录不能绕过邀请。邀请码的并发消费和失败回滚按最终发行/兑换规则验证。

## 产品与前端验收

开发者从创建测试应用到正式审核接入全过程可操作；测试成员限制、待审配置不生效、所有者隔离、暂停及密钥轮换均需验证。已确认旧批准版本在审核期间继续服务、新配置获批后生效，见 [ADR-0008](decisions/0008-application-config-review.md)。测试应验证新旧配置切换无混用、拒绝后旧版本仍有效，以及审核期间并发编辑不会批准错误版本。

Playwright 候选用于注册、登录、授权、退出、开发者申请和管理员审核。中英文、明暗主题、窄屏、键盘、长内容、加载与失败状态均覆盖。SSR 渲染的私人数据不得泄露给其他用户或共享缓存。

对比度、焦点、标签和错误反馈目标参考 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)，自动扫描与人工键盘检查结合，不宣称扫描通过等于全面合规。

管理员 MFA 已纳入首期，必须测试初始化、绑定、错误/重放、恢复码单次使用和丢失恢复，不能只验正常验证码。初始化未完成时不能直接获得可用管理权限；恢复后需按定案流程重新建立 MFA。

## 测试环境与外部依赖

每轮测试使用专属数据库、缓存命名空间和端口；并发任务不得共享可写测试资源。测试验证目标身份，销毁时只清理自己拥有的资源。

CI 对外部供应商使用受控替身，验证协议分支；生产开放前在专属真实测试 client 上手动核验 GitHub/Google 流程，并记录日期与限制。未配置供应商不算测试通过。

邮件以 Mailpit 验证模板、语言、验证码与重试；另验证真实 SMTP 配置和失败处理。禁止向真实用户批量发测试邮件。

## 发布、迁移与恢复

- 构建不可变镜像并记录版本与摘要；禁止依赖浮动 `latest` 作为可回退证据。
- 迁移独立一次性任务执行，成功后放行兼容应用；多个实例不能并发争抢迁移。详细策略见 [backend.md](backend.md)。
- 上线前确认 issuer、回调、TLS、时钟、SMTP、代理信任、密钥持久化、Cookie 与备份恢复。
- liveness 表达进程存活，readiness 表达可接流量；基础设施故障不能造成无限重启风暴。
- 回退需要说明旧应用是否兼容新 schema；已执行的破坏性迁移不以“回滚镜像”解决。
- 数据库备份、签名与加密密钥备份分别控制访问。恢复后能够解密必要数据、验证令牌并按策略处理旧会话。
- RPO、RTO、保留期和演练周期待确认；未做恢复演练不能声称备份可用。

正式发布后关注登录/签发错误率、延迟、邮件/outbox 积压、应用暂停传播、数据库容量和密钥轮换。阈值依据基线制定，不在本轮虚构 SLO 或规模承诺。
