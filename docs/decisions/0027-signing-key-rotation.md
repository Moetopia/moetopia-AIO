# ADR-0027：持久化签发密钥与重叠轮换

日期：2026-10-21。状态：后端已实施常规轮换；生产多实例、外部 RP 及泄露应急待验收。

## 决定

使用原 signing_keys 表，每次 Token 事务锁定并固定 active RSA 私钥，最终签名入口统一 kid，按受控公钥集合验签。常规轮换保留旧公钥十五分钟，期满清空旧私钥；签发最长十分钟的参数变化必须重新评估窗口。命令只由有主机/数据库/根密钥权限的操作人员执行，不提供远程管理 API。

JWKS 实时读取公钥；不以只公布旧公钥代替协议服务对旧令牌的验签支持。初始化、常规签名轮换、泄露应急和数据加密根轮换是不同操作。现有自有会话及刷新 HMAC 不随 RSA 轮换自动失效。

## 代价与重评估

增加索引查询和私钥解析，选择先保证低流量环境的一致性；没有吞吐承诺。只有测量显示瓶颈才加入带失效证据的缓存。部署前确保不存在继续用启动私钥签发的旧实例。若采用 KMS/HSM、更长令牌时效或分离签发服务，需要重新设计 source/密钥保留和错误传播。唯一操作契约见 [签名密钥](../run-signing-keys.md)。
