# ADR-0026：外部身份登录与无密码首登

日期：2026-10-21。状态：用户确认首登不强制本地密码；后端已实施，真实供应商及成品页面验收待完成。

## 决定

GitHub OAuth 与 Google OIDC 通过现有 oauth2/go-oidc 协议库接入，固定 HTTPS 供应商端点，统一使用 S256。外部身份采用 provider/issuer/subject，禁止同邮箱自动合并。首次创建账号必须通过本地邮箱与注册准入，补全不要求本地密码。敏感操作暂沿用现有密码再认证；纯第三方账号先经已验证邮箱设置密码。该交互已由用户确认。

identity 拥有外部凭据及临时登录事务；federation 包为该领域的供应商适配及流程编排，不成为独立租户或任意插件注册引擎。凭据变更与会话撤销、通知、审计同事务；注册将本地验证码、邀请和外部绑定一同消费。短期流程使用加密数据库事务和浏览器绑定，不保存第三方访问令牌。

## 代价与重新评估

增加 has_password 状态、首次补全页面及供应商凭据配置；供应商验证邮箱不直接替代本地邮箱验证，因此步骤较多。若未来加入无需本地密码的敏感操作，应设计独立近期外部再认证与恢复策略，不能直接删除密码检查。多外部账号/同一供应商多身份、额外供应商、长期第三方 API 授权均超出本轮范围。

开发域名回调可登记性、真实供应商登录、限额和故障行为需要实际控制台配置验收。数据库与模拟协议通过不代表这些环节已通过。唯一运行契约见 [联邦登录](../run-federation.md)。
