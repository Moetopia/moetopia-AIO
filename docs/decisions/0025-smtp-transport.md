# ADR-0025：校验 TLS 的 SMTP 通知传输

- 日期：2026-10-21。
- 状态：已授权首期生产运行准备的工程实现；真实外部供应商与正式投递尚未验收。

沿用加密 outbox，增加 STARTTLS 和隐式 TLS，仅开发允许无认证明文 Mailpit。生产默认 STARTTLS，校验系统证书链/主机名，最低 TLS 1.2，不提供跳过校验或降级；认证凭据不进入错误。连接和完整投递均有期限，context 取消关闭底层连接。

当前需求仅为文本安全通知，采用 Go 标准库 net/smtp 与 crypto/tls，不新增邮件依赖。net/smtp 已冻结新增特性，不能据标准库身份推断它将支持新的认证/运营功能；SMTP OAuth2、HTML/附件、供应商 API 或退信集成出现时重新评估专门适配器。标准库负责 SMTP/TLS，Moetopia 只负责安全配置、信封/MIME 和队列边界。

用稳定 Message-ID 支持追踪，不承诺收件方去重；DATA 确认后的 QUIT 失败不重投，接收响应丢失等场景仍遵守至少一次语义。保留有界退避、租约和到期时间。API 不再因“生产传输未实现”无条件拒绝，但其他身份/部署验收仍限制生产交付；真实域名/发件授权、供应商可达、退信/投诉、投递率和容量需实际验证。

接口与验证范围由 [邮件运行说明](../run-email.md) 维护；没有新增迁移或依赖，不修改当前 Mailpit 的实际开发配置。
