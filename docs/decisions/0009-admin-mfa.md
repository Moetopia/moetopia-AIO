# ADR-0009：管理员 MFA 纳入首期

- 状态：首期范围已确认；恢复和初始化细节为建议。
- 记录与确认日期：2026-10-17。
- 确认依据：用户选择首期包含 TOTP MFA、单次恢复码和一次性初始化。
- 实施状态：未实施。

## 已确认决定

首期管理员安全包括 TOTP MFA、单次恢复码和一次性初始化。普通用户 MFA 放在后续，不因管理员能力存在而将普通用户流程一并扩展。

## 理由与代价

管理账号可影响应用审核和身份体系，需要在首期交付完整的第二因素及恢复能力。除验证码验证外，还需维护绑定、加密存储、恢复、重放限制和初始化封闭流程。

## 细节建议与待验证

建议通过一次性 CLI 初始化，限制该入口的生命周期；管理权限只在完成必要绑定后可用，不保留通用绕过 MFA 的后门。

TOTP 种子加密保存，单次恢复码保存验证值。恢复码使用后原子失效；重新生成使旧集合失效。恢复后如何重新绑定、如何处理旧会话和通知，以及全部恢复凭据丢失后的受控处置，均须形成明确方案。

验证时钟偏差、验证码重放、失败限流、并发消费恢复码和丢失凭据场景。不能仅凭 TOTP 库的正常调用就声称恢复流程完整。

## 重新评估条件

若改用其他管理员身份与认证方式，需保留与首期安全目标相当的控制并重新讨论；不以开发方便为由静默移除 MFA。
