# ADR-0033：容器发布、秘密文件与恢复校验

状态：已实施的工程选择；隔离运行结果见[实施进度](../implementation-status.md)，不代表正式生产参数已获确认。

采用单机 Compose，固定摘要基础镜像，多阶段构建、非 root API/account、只读运行文件系统和资源边界。管理员静态 CSR 由入口服务承载；任务嵌入 Go API，首期不新增队列/调度/监控常驻服务。数据库迁移角色与 API CRUD 角色分离。

秘密通过独立受保护文件挂载，不通过构建参数分发。Caddy 覆写专用客户端 IP header，仅对专用网络 CIDR 信任；不采信外部 XFF。指标只在内部接口暴露，固定低基数标签。普通 Compose 文件秘密并非加密秘密存储，磁盘与目录权限仍由运维负责。

备份采用 PostgreSQL custom dump 直接 age 加密，根密钥使用不同 recipient 单独托管；恢复只允许全新专用命名数据库。验证原根密钥后，单事务撤销瞬态凭据并保留长期账号/应用。另提供停止全 issuer 后的应急签名轮换，原子废止旧密钥及全局瞬态凭据。正常轮换仍维持十五分钟窗口。

代价：短维护窗口、备份密钥管理、定期恢复演练和下游会话撤销协调。归档不会恢复快照后的安全变更；镜像摘要也不能替代漏洞跟踪。硬件、真实 SMTP/供应商、正式域名、异地存储/调度/保留策略及生产 SLO 尚未确定。

重新评估条件：真实混合负载超出单机预算、长任务拖累请求、独立发布需求、可靠异地恢复/连续归档要求，或需要组织级秘密管理。届时据实拆任务进程或引入外部秘密/备份设施，不预建空微服务。
