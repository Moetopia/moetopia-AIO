# ADR-0029：应用显式测试成员

日期：2026-10-22。状态：按已授权首期范围实施；20 人限额为可调整的开发基线，不是用户逐项确认的商业额度。

产品要求测试态只对所有者与显式成员开放。采用既有平台 UUID 名单，不增加账号目录搜索、邮箱邀请、团队角色或配置管理权限。唯一有效名单由 authorization 持有，developer 编排 revision、身份状态、审计和 outbox。名单在未发布应用生效，公开发布后不成为普通用户登录的额外限制。

移除资格同时撤销现有测试授权族，在线凭据读取再次检查资格；重新添加必须重新授权。添加按主体 UUID 顺序获取身份锁，再锁应用/client/grant，避免交叉添加死锁及删除残留；所有者/成员通知失败整笔回滚。代价是在线用户凭据读取增加客户端索引查询，非所有者测试凭据还需名单索引查询；低流量下优先正确性，不据此承诺吞吐。没有新增独立服务、缓存失效通道或通用 RBAC。

接口、数据和离线 JWT 撤销窗口由 [测试成员契约](../run-test-members.md) 维护；迁移及验证事实由 [实施进度](../implementation-status.md) 维护。重新评估条件：团队管理、成员自助邀请/退出、明确的更大额度、实测查询瓶颈或应用分库。新增团队角色不能通过扩展此名单暗中实现。
