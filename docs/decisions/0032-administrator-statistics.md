# ADR-0032：管理台指标与通知重投

日期：2026-10-22。状态：首期后端实施；图表和真实外部邮件验收另计。

管理台从模块所有者读取当前账号、应用和通知状态，不跨域联表或使用分页长度拼出全站数字。注册趋势在 identity 成功创建账号的同一事务写入最小匿名日期事件，保留采集起点和三十个 UTC 日期；不从短期会话或会被删除的用户记录回填历史。

通知运维仅提供耗尽记录的非秘密元数据和有条件的重排。重排不延长原期限、不披露正文或收件人，与审计同事务，SMTP 投递仍由已有 worker 执行。代价是统计写入失败会回滚注册，图表只能展示采集后的真实覆盖，后台查询需要若干有界聚合；当前不增加消息队列或单独指标服务。

字段、期限和错误由 [管理台统计与邮件运维](../run-admin-statistics.md) 定义，验证由 [实施进度](../implementation-status.md) 定义。唯一用户、长期经营分析、财务计量、海量事件聚合及通知箱均需另行设计。
