# ADR-0028：显式中央退出与受审回跳

日期：2026-10-21。状态：后端实施；确认页面、正式第三方 RP 及生产验收待完成。

## 决定

保留现有本地退出，新增 Go RP 先本地结束、再请求 OP 显式确认的流程。OP 只结束当前中央会话，不暗示结束其他 RP/设备或撤销 OAuth 授权。退出地址独立于登录回调登记，进入已发布配置审核；确认时重新验证生效列表，拒绝任意跳转。

复用现有 JWT/会话、AEAD、事务与审计设施；OP 使用专用短期事务，RP 使用独立用途的短期证明。自有 RP 不为了退出保留 token，使用 client_id 及固定注册地址。确认需要 account CSRF 和当前展示主体，RP 发起则使用本应用 Cookie/CSRF；两者不能混用。

## 代价与边界

增加确认页与配置字段，RP 本地先退出后不能因中央拒绝而复活。当前不提供 front/back-channel、宽泛 logout_hint 或长期过期 ID hint 关联能力。所有动作的实际对象和错误由 [运行契约](../run-logout.md) 唯一定义，不将服务端验证当作页面已完成。
