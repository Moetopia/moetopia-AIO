# ADR-0020：账号安全版本、资料与恢复事务

- 日期：2026-10-19。
- 状态：已授权首期范围的开发实现及数据库验证；下述具体限额为开发基线，未视为生产参数确认。
- 范围：扩展 ADR-0014/0018/0019，不改变 Go 会话所有权和 JWT 协议实现。

账号资料使用 revision 条件写入，身份凭据使用独立 security_version；不能因为改昵称使全部会话失效，也不能只撤销当下浏览器会话而保留旧密码签发的刷新能力。改密码、恢复和邮箱确认在用户行锁下递增安全版本、消费挑战、撤销自有会话并记录审计/安全通知；授权码、刷新、UserInfo 和会话创建检查版本。

恢复挑战与邮箱变更分用途 HMAC，绑定事务和目标；邮箱变更另绑定发起 RP 会话与当前密码。错误计数需提交，不能因返回验证失败回滚而允许无限尝试。开始恢复对未知账号写入相同形状的挑战及加密任务，任务带服务端 suppressed 标记不发信；这改善可观察差异，不宣称严格恒定耗时。成功不自动登录。设计参考 [OWASP Forgot Password](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)。

头像先存 identity 的 bytea，原图在内存限额内检查后重编码，避免为低流量身份产品预建对象存储平台；图片处理限制并发，热路径不选择 blob。代价是数据库备份体积增加，必要时迁移到受管对象存储，保留稳定头像接口。实现使用 Go image 与 golang.org/x/image/draw；不接受 SVG 等主动内容，依据与 API 见 [Go image 文档](https://pkg.go.dev/image)。

个人安全日志保留 90 天并展示最近 50 条；当前事件内容尚不足完整管理员审计，不能据此完成后台安全验收。公开下游离线 JWT 仍有到期残留窗口，现有 RP 会话不因单个 grant 撤销而自动结束。完整契约、已执行迁移 6、兼容/Down 风险及测试证据由 [账号接入](../run-account-management.md) 维护。

重新评估条件：生产邮件接入、恢复滥用或投递时序风险、头像流量/数据库体积、下游要求更短撤销窗口、管理员角色和七天注销接入。不得用此 ADR 将尚未实现的注销、联邦绑定或生产恢复称为完成。
