# ADR-0014：账号注册、会话与开发预览基线

- 状态：当前开发实现；参数是可调整的工程基线，尚未进行生产验收。
- 日期：2026-10-18。
- 背景：用户要求继续开发，并希望自己运行服务、随修改查看效果。先完成可操作的账号路径，保留后续 OIDC、管理 MFA 与应用接入的边界。

## 身份与数据

注册分成发送邮箱验证码与确认创建两步。邮箱当前仅支持 ASCII 地址，去首尾空白、整体转为小写；不做特定供应商去点或去加号。邮箱唯一性由数据库保证。昵称长度 1–80 字符，用户标识使用 UUID，与邮箱分离。

密码采用 [Argon2id](https://pkg.go.dev/golang.org/x/crypto/argon2)，当前参数为 64 MiB、3 次、1 路并行，每次随机 16 字节盐、输出 32 字节。哈希包含算法与参数，验证器只接受受支持的固定参数组合，不根据任意数据库值分配无界资源。进程最多两个并行哈希；参数仍需在目标机器测量。参考 [OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)，不将选定参数描述成性能验收。

当前密码至少 15 个 Unicode 字符、最多 256 字节，不额外要求字符混合，允许粘贴。尚未接入泄露密码库，生产上线前补齐政策与验证，不因此弱化哈希或最小长度。

邮箱验证码为随机 8 位数字、10 分钟有效、最多 5 次错误验证；数据库保存绑定用途/事务/邮箱的 HMAC，不能用数据库中的低熵普通哈希离线穷举。确认创建时，在同一 identity 事务中条件消费验证码、消费邀请码并创建已验证用户；任何失败回滚，不因“先查再写”允许重复兑换。账号创建成功后由用户明确登录，不在部分成功的跨模块流程中假装已登录。

## 邮件与事务边界

发送验证请求时，identity 存储适配层协调一个明确的 Ent 事务：创建验证码记录，并调用 notifications 的 Enqueue 接口写入同事务 outbox。identity 不直接查询通知表；notifications 适配接口接收事务 Client，这是当前单库跨模块事务的显式耦合。将来拆库需改为已持久化事件与消费者，不把这个接口直接跨进程搬用。

通知载荷使用应用加密主密钥和独立用途加密，包含验证码的密文到期删除。后台通过条件更新领取 30 秒租约，至少一次投递、最多 5 次尝试，指数退避加抖动；成功删除任务，未送达任务到期清理。故障日志不包含收件人、正文或秘密。当前没有人工重投控制台或完整队列监控，不声称通知运维已完备。

当前 SMTP 适配器仅用于开发 Mailpit；API 的 production 启动明确拒绝，直到完成生产邮件传输和其余身份验收。验证码状态和到期会话按一分钟周期清理；检查有效期不依赖清理准时发生。

## Web 会话

本轮只开放 account 应用会话。Cookie 携带 32 字节随机不透明句柄，服务端只保存 SHA-256 哈希；绝对有效期 7 天，登录成功旋转句柄和 CSRF 值。Cookie 为 HttpOnly、Host-only、Path=/、SameSite=Lax；生产配置使用 Secure 和 `__Host-` 名称，但生产链路尚未开放。

写请求同时验证固定账号 Origin 和由 HttpOnly 句柄派生的用途专属 CSRF 值，不接受任意代理头构造可信 origin，参考 [OWASP CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。身份 Cookie 不作为 OAuth access token，也不直接用于 admin/developer。普通账号登录不会赋予管理员权限。

验证码发送及密码请求依赖 Valkey 限流，故障时拒绝。当前按直接连接 IP 和目标值哈希限流；Nuxt 开发代理下 IP 是代理地址，这只是开发基线，生产需先定义可信入口及实际客户端地址来源，不能直接信任 X-Forwarded-For。

会话列表最多返回最近 100 个有效 account 会话，当前只展示登录和到期时间，不伪造浏览器设备识别。撤销检查账号所有权；退出删除服务端记录。后续敏感资料修改、近期认证、异常登录和跨应用 SSO 仍需独立实现。

## 验证与剩余事项

当前证据以 [实施进度](../implementation-status.md) 为准，日常反馈流程见 [开发预览](../live-development.md)。新迁移为版本 2，独立新增三个 schema；旧版 authorization 表不变。只向已有专属开发库执行，不在启动时自动迁移。

生产邮件、泄露密码筛查、审计、密码恢复、联邦登录、管理员 MFA、应用审核及标准 OIDC 仍未完成。开发 CLI 邀请仅允许 development，不能当作生产管理员授权入口。发布前还需重新核对依赖告警、限流参数、SMTP/队列故障恢复与备份恢复。
