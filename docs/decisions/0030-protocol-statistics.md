# ADR-0030：真实协议事件与有界统计窗口

日期：2026-10-22。状态：按已授权计划实施应用级统计；管理台全局统计仍未交付。30 个 UTC 日期和每轮清理 1000 条为当前工程基线，可按实测调整。

用量必须有可解释的真实来源。不能将短期 grants 的创建时间当累计调用量，也不能用审计保留期或前端常量伪装历史。采用与授权/签发同事务的最小事件记录，仅包含 client、UTC 日期和事件种类；查询在数据库按日期和种类聚合。保留采集起点，开始前日期不返回 counts，不凭空回填零值。

每次成功事务多一次插入，统计存储失败会使协议事务失败；交换失败不计成功且不会消费有效的待兑码。选择追加短记录避免全局或单 client 日计数热点锁，代价是随成功次数增长的短期存储；现有低流量预期下保持单 PostgreSQL/worker，无新服务或缓存。物理 client 删除级联清理，无用户或原始凭据标签。

完整字段、计数口径、30 天清理和兼容代价见 [统计契约](../run-statistics.md)，验证与迁移事实见 [实施进度](../implementation-status.md)。重新评估条件：实际吞吐/存储超预算、计费或可审计账务、长期留存、多实例升级空窗、唯一用户指标及管理台概览。账务系统不能未经另行设计复用本统计当扣费真相源。
